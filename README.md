# CareerTrack Backend

CareerTrack is a full-stack career and job application management platform.

## Features

- JWT authentication
- Profile management
- Skills, education and experience CRUD
- Projects and certifications CRUD
- Job application tracking
- Dynamic dashboard statistics
- Swagger API documentation
- Flyway database migrations

## Technology Stack

- Java 21
- Spring Boot
- Spring Security
- PostgreSQL
- Spring Data JPA
- Hibernate
- Flyway
- Maven
- Docker
